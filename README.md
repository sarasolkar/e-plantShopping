# e-plantShopping

**Repository Name:** e-plantShopping

## Paradise Nursery - React Shopping Application

e-plantShopping is a React and Redux based shopping application developed for the IBM React Final Project. The application allows users to browse different categories of houseplants, add plants to a shopping cart, update quantities, remove items, and view the total cart amount.

## Features

- Browse houseplants grouped into multiple categories.
- View each plant's image, name, description, and price.
- Add plants to the shopping cart.
- Automatically disable the **Add to Cart** button after adding an item.
- Increase or decrease item quantities in the cart.
- Remove items from the cart.
- View the total cart amount and individual item totals.
- Responsive navigation with Home, Plants, and Cart pages.

## Technologies Used

- React
- Redux Toolkit
- React Redux
- Vite
- JavaScript
- CSS
